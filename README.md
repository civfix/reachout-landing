# reachoutla.org

The website for Reach Out Los Angeles, a 501(c)(3) nonprofit.

## How the site is organized

| Folder | What it is |
|---|---|
| `drafts/` | **Edit these.** The source pages, styles, scripts and images. |
| `dist/` | **The live site.** Generated by the build script; Cloudflare publishes this folder. Don't edit it by hand. |
| `tools/` | Helper scripts: the build, a local preview server, and generators for the hills and the LA map. |
| `functions/` | Server code for an on-site Stripe donation page (not in use yet; donations go to the Stripe link). |

## Making a change

1. Edit the page in `drafts/` (for example `drafts/team.html`).
2. Rebuild the live site:
   ```bash
   python3 tools/build_site.py
   ```
3. Preview it the way Cloudflare will serve it:
   ```bash
   python3 tools/serve.py
   ```
   Then open http://localhost:8790. Press Control + C to stop.
4. Commit your changes on a branch and open a pull request.

If you change a `.css` or `.js` file, bump its `?v=` number in the pages that load it, so browsers fetch the new copy.

## Adding an update (article)

1. Copy an existing article in `drafts/` (for example `update-civfix-launch.html`) and edit it.
2. Add it to `PAGES` in `tools/build_site.py` with its address, title, description and date.
3. Add a card for it in `drafts/updates.html` (and on the homepage if it's one of the two newest).
4. Build and preview as above.

## Publishing

**Merging into `main` publishes the site automatically** (Cloudflare Workers Builds). Never merge until the change has been previewed. Cloudflare keeps earlier versions, so a bad deploy can be rolled back from the Cloudflare dashboard.

## House style

- **civfix** is always written in lowercase, even at the start of a sentence.
- Every fact, statistic, quote and photo permission must be real and confirmed. No placeholders go live.
- Text always sits on paper, never directly on the cork, so it stays readable.
